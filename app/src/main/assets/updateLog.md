## cronet版本: 128.0.6613.40

## **必读**

【温馨提醒】 *更新前一定要做好备份，以免数据丢失！*

* 阅读只是一个转码工具，不提供内容，第一次安装app，需要自己手动导入书源，可以从公众号 **[开源阅读]**
  、QQ群、酷安评论里获取由书友制作分享的书源。
* 正文出现缺字漏字、内容缺失、排版错乱等情况，有可能是净化规则或简繁转换出现问题。
* 漫画源看书显示乱码，**阅读与其他软件的源并不通用**，请导入阅读的支持的漫画源！

**2026/08/15**

升级提示
* 本版数据库由 v87 升级至 v91，首次启动时自动迁移，更新前请先备份数据

朗读引擎
* HTTP 在线朗读新增角色化朗读：经用户授权后，由用户配置的外部 AI 服务标注旁白和角色，并支持按角色指定引擎与音色
* 角色音色表随书保存，引擎音色清单支持编辑
* 章节标注结果自动缓存；标注或配音解析失败时回落普通朗读
* HttpTTS 补齐 jsLib 和启用 CookieJar 选项

书源/规则
* 登录 UI v2 支持多步流程、倒计时、下拉选择、清除登录信息和 toggle 登录开关
* 增强书源网页会话桥接，关联书源的网页可访问全局缓存、书源数据和登录凭据，请仅对可信书源使用
* 文件源支持下载导入
* MCP 服务：新增 Bearer Token 鉴权，工具增至 23 个
* 书源加密兼容层改用 Android/JDK 原生 API，移除 Hutool 依赖

界面
* 高亮新增 5 种背景形态（圆角/马克笔/半高/基线/胶囊）与阴影发光效果
* 主题自定义配色：日夜双联预览，四色日夜分别调整
* 图片 URL 支持内联 style 选项，可为单图独立设置排版模式及 width/height
* 日志面板支持类别色条、过滤、实时刷新和导出分享
* 书架布局设置改为底部面板，发现页增加分组筛选
* 段评图标升级为图标库管理：支持保存多份 SVG 图标，预览、编辑、删除并一键切换，旧自定义图标自动入库
* 辅助按键浮窗支持设置显示行数

其他
* 帮助文档支持全文搜索和两级章节目录，重写定时任务帮助
* 启动时自动检查更新，更新弹窗显示安装包大小和发布日期，并支持忽略版本
* 修复 Web 代码编辑器在 Android 端的交互问题
* 代码编辑器语法检查上限放宽至 12 万字符，超限显示暂停提示，不再隐藏语法状态栏
* 修复口令识别、华为导航栏显示、高亮定位偏移等问题

* JS源编辑页切换CodeMirror编辑器，调试按钮提级到工具栏，单选导出/分享.js原文
* 新增MCP服务：设置中开启后AI助手可直连App保存/调试/管理书源、查看HTTP日志

界面

其他
