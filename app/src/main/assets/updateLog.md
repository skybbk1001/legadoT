## cronet版本: 128.0.6613.40

## **必读**

【温馨提醒】 *更新前一定要做好备份，以免数据丢失！*

* 阅读只是一个转码工具，不提供内容，第一次安装app，需要自己手动导入书源，可以从公众号 **[开源阅读]**
  、QQ群、酷安评论里获取由书友制作分享的书源。
* 正文出现缺字漏字、内容缺失、排版错乱等情况，有可能是净化规则或简繁转换出现问题。
* 漫画源看书显示乱码，**阅读与其他软件的源并不通用**，请导入阅读的支持的漫画源！

**2026/11/04（自动任务诊断增强）**

* 补齐自动任务服务启动、前台启动拒绝、超时、停止及销毁日志，记录闹钟预约/触发时间、唤醒延迟和相关权限状态
* 增加批次和任务开始/阶段/结束记录、未开始/运行中/完成/失败/中断计数，以及运行期间每 30 秒的状态快照
* 自动任务基础诊断独立限容保存，不依赖“记录日志”开关，可通过“关于 → 保存日志”导出；不额外记录脚本、Cookie、请求正文或返回内容
* 本次用于定位 Android 16 上自动任务静默停止，保持原调度策略；诊断增强不代表已修复全部设备上的停止问题

**2026/10/18（测试版）**

升级提示
* 数据库由 v93 升级至 v94，首次启动自动迁移；升级前请先备份，迁移后的数据库不能直接由旧版读取，如需回退请使用升级前备份

发现与 MCP
* 恢复可选的旧版发现页：设置 → 其它设置 → 使用旧版发现页，按书源展开分类，默认仍为新版卡片页
* MCP 新增发现卡片查询、添加、批量添加、更新和删除工具，支持跨书源批量创建、全部/动态分类和逐卡配置
* 批量最多提交 50 项，任一无效书源或参数会使整批报错，不会部分添加；追加不覆盖旧卡片，重复调用仍会新增卡片

阅读记录与听书
* 阅读记录增加作者与封面快照，按书籍 URL 区分同名书，尽量保留移出书架后的展示信息
* 兼容旧记录迁移，只有能唯一匹配在架书籍时才补全作者和封面；旧备份按同设备同书籍身份合并，重复恢复不重复累加同一份时长
* 修复翻页、朗读和音频计时在切书、暂停及开关记录时的边界问题，修复中英文大字体下两行时间重叠
* 音频页菜单新增“播放速度”：0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 3 倍，保留 ±0.1 倍微调并保存速度

书源与界面
* 修复 v1/v2 登录 UI 的动态表单、按钮及登录脚本中的 java.open 页面扩展绑定
* 补齐交互回调/登录脚本四参 java.open("rss", articleUrl, title, rssSourceUrl)，按已导入的目标订阅源加载未缓存文章，不覆盖已有正文，跳转受原页面生命周期约束
* 修正封面背景、图片、前景的圆角裁切及书架/发现卡片角部露底，补充既有浅色文字修复的回归测试

Nostr 段评改进
* 新增“最热/最新”排序和下拉刷新，最热列表穿插新评论，后台补充时保留已有排序
* “发送中/草稿”状态跨弹窗保留，失败草稿落盘，重启后重开对应段评可恢复并点击重发
* 发布成功原位更新占位，修复成功后残留“发送中”；断网或发布失败时保留已有可用的段评缓存
* 未定位段评入口移至最后一段旁独立气泡，取消额外章末占位行

测试提示
* 已通过 85 项聚焦 JVM 和 API 34 模拟器 14 项回归，Debug 与 AndroidTest APK 构建成功；不代表已签名发布包或全场景验收，全量 JVM 尚有既有原生库环境及静态断言失败
* 原登录/RSS 源真实网络、Nostr 签名器与中继交互、Android 16 厂商硬件圆角及完整日夜切换仍需实机反馈
* 未新增或恢复“明月书阁”订阅源，仍需可验证站点地址或旧源规则

**2026/10/15**

Nostr 段评
* 新增 Nostr 段评：从 Nostr 中继读取公开段落评论，连接远程签名器后可在正文对任意段落发布评论或回复
* 以 Nostr 远程签名器（NIP-46）连接账号，支持 bunker 地址与二维码配对，中继发起鉴权时自动打开授权页
* 新增本机签名器（NIP-55）：安装在同机的签名器 App（如 Amber）可直接授权签名，请求不经中继，签名器中继不可达时也能发布
* 签名器入口合并为一个：该行显示头像、昵称与可点击复制的公钥，右侧为连接 Nostr / 退出；弹窗内提供二维码配对、本机签名器、bunker 三种方式，本地与远程签名器可并存并自由切换
* 发布事件携带 NIP-89 客户端标签与段落哈希标签，摘录补充 relay hint 并投递到摘录所在中继
* 支持点赞与再次点击取消（NIP-09 删除自己的 reaction）
* 支持五级嵌套回复
* 段评列表优先展示头像与昵称，登录后自动同步账号资料（kind 0）

Nostr 中继
* 中继改为用户配置，支持一键自动发现（NIP-11 元数据探测 + WebSocket 健康检查）并缓存可用结果

阅读体验
* 无段评的段落，选中段落时临时显示并可经选择菜单评论
* 发布/回复乐观上屏并显示进度、防止重复提交，失败转为草稿态可点击重发
* 发布/回复后段评气泡立即乐观 +1，失败回退
* 段评统计与详情落盘缓存，详情缓存跨重启保留，打开章节时预热当前章与下一章
* 段评书标识升级，章节标题纳入定位信息；跨书源按段落内容匹配，兼容重新分段的章节，未定位段评汇总到章末

备份/恢复
* 备份与恢复包含 Nostr 账号（非敏感字段），恢复后需重新连接远程签名器

其他
* 校验中继返回事件的签名
* 修复段评回复跨摘录时列表少于计数的问题
* 修复打开书籍、关闭段评弹窗时的段评刷新崩溃与线程错误
